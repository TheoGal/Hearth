# Custom tile icons

Upload pictures here to replace tile icons on the Hearth home screen.

- Name each file after the app or input ID, for example `netflix.png` or `com.webos.app.hdmi1.png` (HDMI 1). HDMI 2 to 4 are `com.webos.app.hdmi2` to `com.webos.app.hdmi4`.
- PNG or JPG. Square works best, 256x256 or 512x512 is plenty.
- For other apps, the file name is the app's ID (for example `netflix`, `youtube.leanback.v4`, `amazon`). Ask Claude if you are unsure of an ID.
- Each upload starts a new build. Install the new IPK from Releases to see the icons.
- To go back to the original icon, delete the file.
